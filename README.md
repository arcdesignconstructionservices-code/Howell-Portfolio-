# Howell Valeros — Portfolio

Personal portfolio built on the iPortfolio Bootstrap template (BootstrapMade), restyled in dark blue / black / white, with clickable work cards, an ecosystem map and an animated canvas hero. No build step.

## Run locally
Open `index.html`, or: `npx serve .`

## Customize
- Works: `WORKS` array in `assets/js/custom.js` (also drives the ecosystem map)
- Colors: top of `assets/css/custom.css`
- Contact email: `CONTACT_EMAIL` in `assets/js/custom.js`
- Photo: `assets/img/howell.jpeg`
