# Hwl+ — Portfolio

Static portfolio site for an AI development studio (Howell & Gab). No build step.

## Run locally
Open `index.html`, or: `npx serve .`

## Customize
- Company name: search/replace "Hwl+" in `index.html`
- Projects, team, stats: edit `index.html`
- Contact email: `CONTACT_EMAIL` in `script.js`
- Colors: CSS variables at top of `styles.css`

## Deploy free
GitHub repo → Settings → Pages → Deploy from branch `main` / root.
