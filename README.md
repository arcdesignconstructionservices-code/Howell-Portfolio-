# Howell Valeros — Portfolio

Built on the iPortfolio Bootstrap template (BootstrapMade) with Howell's real details, an animated canvas hero background, and a details page per work. No build step.

## Run locally
Open `index.html`, or: `npx serve .`

## Customize
- Works: `assets/js/works.js` (details pages read from it); cover images are in `assets/img/portfolio/`
- Contact email: `CONTACT_EMAIL` in `assets/js/custom.js`
- Photo: `assets/img/howell.jpeg`
