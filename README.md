# Howell Valeros — Portfolio

Personal portfolio of Howell Valeros: warm neutral palette, interactive ecosystem map, and case studies from Torero Global Outsourcing Corp. No build step.

## Run locally
Open `index.html`, or: `npx serve .`

## Customize
- Projects: `PROJECTS` array at the top of `script.js` (also drives the map)
- Colors: CSS variables at top of `styles.css`
- Contact email: `CONTACT_EMAIL` in `script.js`
- Photo: `assets/howell.jpeg`
